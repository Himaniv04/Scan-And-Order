# Scan & Order 🍽️

A contactless food ordering system. Users scan a QR code, provide their details, and access the menu. They can then select items, manage their cart, and place an order directly from their table.

---

### 🚀 Live Demo

**[Click here to see the project in action!](https://scan-order-food.onrender.com/)**

---

### ✨ Key Features

* **📱 QR Code Scanning:** Access the menu by scanning a unique QR code at the table.
* **📝 User Details:** Users enter their name and mobile number before placing an order.
* **🍽️ Dynamic Digital Menu:** A clean and responsive menu built with HTML, CSS, & JS.
* **🛒 Cart Management:** Easily add items, remove items, or change quantities.
* **📤 Direct Order Placement:** Send the order directly to the kitchen panel.
* **🍳 Real-time Chef Panel:** Kitchen staff receive new orders in real-time.
* **🧾 Receipt Generation:** Download a receipt after the order is completed.

---

### 🛠️ Technology Stack

* **Front-End:** HTML5, CSS3, JavaScript
* **Back-End:** Node.js, Express.js
* **Database:** MongoDB

---

### ⚙️ How It Works

1.  The **User** scans the QR code at their table.
2.  They enter their name and mobile number.
3.  They browse the menu and add items to the cart.
4.  The user confirms and places the order.
5.  The **Chef/Admin** receives the order instantly on the "Chef Panel".
6.  The user can download a receipt upon completion.
